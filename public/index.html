            Language reference
            x = expr
            Name a series. Every value is a series, one number per bar.
            x[n]
            Value n bars ago.
            open high low close volume
            Price series. Also hl2 hlc3 bar.
            + - * / < > <= >= == !=
            Math and comparisons, bar by bar.
            and or not
            Combine conditions.
            sma ema wma (src, n)
            Moving averages.
            rsi(src, n)
            Relative strength, 0 to 100.
            stdev(src, n)
            Rolling standard deviation.
            highest lowest (src, n)
            Rolling max and min.
            atr(n)
            Average true range.
            vwap()
            Volume-weighted average price, resets daily.
            change roc (src, n)
            Difference and % change vs n bars ago.
            crossover crossunder cross (a, b)
            True on the bar a crosses b.
            iff(cond, a, b)
            Pick a or b per bar.
            abs max min
            Element-wise helpers.
            plot(x, "label", "#hex")
            Draw on the price chart.
            panel(x, "label", "#hex")
            Draw in the lower pane.
            columns(x, "label")
            Histogram in the lower pane.
            hline(value)
            Reference line in the lower pane.
            buy when cond
            Go long at the next bar's open.
            sell when cond
            Exit (or go short, if shorts is on) at the next bar's open.
            alert "msg" when cond
            Push a notification when a bar closes with cond true.
